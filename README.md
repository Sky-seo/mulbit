# 물빛

수면을 지난 햇빛이 수영장 바닥에 그물 무늬를 맺는 과정을, 수심을 바꿔 가며 보여 주는 WebGL2 시뮬레이터.

**[데모 열기](https://sky-seo.github.io/mulbit/)**

바닥의 무늬는 이미지 텍스처가 아니라 매 프레임 계산한 결과입니다. 물결치는 수면의 각 지점에서 햇빛을 굴절시켜 바닥에 닿는 자리를 구하고, 광선이 얼마나 촘촘히 모였는지에서 밝기를 얻습니다. 그래서 얕은 물에서는 무늬가 없다가, 특정 깊이에서 가장 선명해지고, 더 내려가면 다시 흐트러집니다.

## 깊이에 따라 일어나는 일

| 구간 | 바닥의 모습 |
| --- | --- |
| 얕은 물 | 꺾인 빛이 흩어질 거리가 없어 바닥이 고르게 밝다 |
| 빛이 모이기 시작 | 볼록한 물결이 렌즈처럼 작용해 부드러운 무늬가 떠오른다 |
| 초점 구간 | 빛이 가는 선으로 모여 그물 무늬가 가장 선명하다 |
| 초점 너머 | 광선이 서로 엇갈려 선이 갈라지고 겹친다 |
| 깊은 물 | 빨간빛이 먼저 흡수되어 푸르게 가라앉고, 선이 번진다 |

초점이 맺히는 깊이는 물결의 곡률에서 계산해 수심계에 함께 표시합니다. 물결을 세게 하면 곡률이 커져 초점 구간이 얕은 쪽으로 올라옵니다.

## 조작

| | |
| --- | --- |
| 화면 누르기·끌기 | 그 자리에 물결이 번진다 |
| `D` | 모든 UI를 감추고 물만 남긴다 (`Esc`로 복귀) |
| 수심 | 0.05 m ~ 8 m |
| 반복 | 5 m까지 내려갔다 얕은 물로 올라오기를 되풀이 |
| 물결 세기 | 수면의 거칠기. 초점 구간이 함께 움직인다 |
| 해 높이 | 25° ~ 90°. 낮을수록 빛이 비스듬히 들어가 경로가 길어진다 |
| 윤슬 | 수면에서 반짝이는 빛의 양 |
| 색 분산 | 파장별 굴절률 차이. 올리면 무늬 가장자리가 무지개로 갈라진다 |
| 탁도 | 물 속 산란 입자의 양 |

## 계산 방식

**수면** — 40개의 파동을 겹쳐 만듭니다. 각 파동의 진동수는 중력파·표면장력파 분산 관계 `ω² = gk + σk³/ρ` 를 따르므로, 짧은 잔물결이 긴 물결보다 빠르게 지나갑니다. 클릭으로 생기는 물방울 파문은 별도의 파동 방정식 격자에서 풀어 더합니다.

**바닥의 빛(코스틱)** — 수면 격자의 각 점에서 빛을 굴절시켜 바닥에 닿는 점으로 보내고, 그 사상의 야코비 행렬식으로 밝기를 구합니다. 행렬식은 삼각형 면적을 비교해 근사하지 않고, 수면의 곡률(헤시안)에서 바로 미분해 격자점마다 해석적으로 계산합니다. 덕분에 밝기가 삼각형 단위로 끊기지 않고 매끄럽게 이어집니다. 곡률은 수면 패스에서 파동의 2계 도함수로 함께 구워 둡니다.

**색** — 빨강·초록·파랑의 굴절률(1.3310 / 1.3345 / 1.3400)을 따로 써서 세 번 굴절시킵니다. 흡수는 순수한 물의 계수(1/m 단위로 0.45 / 0.065 / 0.018)를 써서, 바닥까지 내려갔다 눈까지 돌아온 경로 길이만큼 감쇠시킵니다. 빨간빛이 먼저 사라지는 이유입니다.

**번짐** — 해는 점이 아니라 약 0.53°의 원반이므로, 깊이에 비례해 무늬가 번집니다. 이 번짐 폭을 밉맵 단계와 흐림 반경으로 환산해 적용합니다.

**윤슬** — 1~4 cm짜리 잔물결을 따로 얹어, 각각이 해를 비추는 순간을 좁은 반사 lobe로 잡아냅니다. 잔물결은 바람 자국처럼 조각조각 몰려다닙니다.

## 요구 사항

WebGL2와 부동소수점 렌더 타깃(`EXT_color_buffer_float`)이 필요합니다. 최신 Chrome, Safari, Firefox에서 동작합니다. 지원하지 않는 환경에서는 안내 문구가 대신 표시됩니다.

의존성 없는 단일 HTML 파일입니다. 빌드 과정이 없으니 `index.html`을 그대로 열면 됩니다.

성능이 부족한 기기에서는 프레임 시간이 길어질 때 격자 밀도를 자동으로 절반으로 낮춥니다. 모바일에서는 처음부터 낮은 해상도로 시작합니다.
